# 来源与版本

技术报告见technical-report.pdf。代码源于状态约束数字身份验证实验工程；独立仓库通过PATH或环境变量配置外部工具，移除了本机依赖目录注入，未改动身份验证规则。原始文件与发布文件摘要见source-manifest.json。

历史统计来自aggregate_20260909T135926，包括已完成批次、性能和接收方隔离实验的记录。发布时新生成的28条基础用例与该历史统计分开。

依赖：Geth 1.13.15、solc 0.8.24、Python 3.12及requirements.txt、独立复核所用Node.js。依赖按各自许可证使用，本仓库不包含其二进制文件。
